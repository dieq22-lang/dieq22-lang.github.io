Privacy policy

Last updated: October 5, 2026

Rez Bot is a personal tool used by one person, its author, with the author's own Google account. It is not offered to anyone else.

What Google data it accesses

Rez Bot requests read-only Gmail access (gmail.readonly). It only reads messages that carry one Gmail label (“Reservations”), which holds restaurant-reservation emails from Resy and OpenTable. It never sends, modifies, labels, or deletes email.

How the data is used

From those emails it extracts the restaurant name, date, time, party size, and booking link, and sends that summary to the author's own Telegram chat.

Storage and sharing

Extracted details are stored in a local database on the author's own computer. To help read and interpret these emails, their text may be sent to the Anthropic API (Claude) solely to produce the summary above for the author; it is not used there to train models. Other than that, Google user data is not sold, shared with third parties, or used for advertising. The OAuth token is stored locally and access can be revoked at any time at myaccount.google.com/permissions.

Rez Bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
